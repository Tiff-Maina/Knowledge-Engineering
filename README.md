**About Exercise 4**  

A knowledge base stores 40 directed road facts across 29 Kenyan towns and 29 region facts. 

A forward-chaining engine applies six inference rules to derive towns, connections, reachability, dead ends and legal moves. 

Uniform Cost Search then plans the lowest-cost route from Nairobi to Kisumu (347 km), which a simulated trailer agent follows, verifying each move against the knowledge base.
